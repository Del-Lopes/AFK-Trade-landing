# Trader AFK — Landing Page

A production-oriented landing page for the Trader AFK ecosystem, built with React and TypeScript.

## Overview

The project focuses on a responsive marketing experience for a financial-technology product, with reusable UI sections, animation, validated forms and structured page composition.

## Tech Stack

- React
- TypeScript
- Vite
- Tailwind CSS
- Framer Motion
- React Hook Form
- Zod
- React Router

## Engineering Focus

- Component-based UI architecture
- Responsive design
- Form validation with Zod and React Hook Form
- Client-side routing
- Animation and interaction with Framer Motion
- Reusable marketing sections
- Production-oriented Vite builds

## Development

~~~bash
npm install
npm run dev
~~~

## Production Build

~~~bash
npm run build
npm run preview
~~~
