# Trader AFK — Landing Page

A production-oriented landing page for the Trader AFK ecosystem, built with React and TypeScript.

## Overview

The project focuses on a responsive marketing experience for a financial technology product, with reusable UI sections, animations, forms and structured page composition.

## Tech Stack

- React
- TypeScript
- Vite
- Tailwind CSS
- Framer Motion
- React Hook Form
- Zod
- React Router

## Development

~~~bash
npm install
npm run dev
~~~

## Production Build

~~~bash
npm run build
npm run preview
~~~

## Engineering Focus

- Component-based UI architecture
- Responsive design
- Form validation
- Client-side routing
- Animation and interaction
- Production-ready Vite build
